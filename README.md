# 나들이 코스 추천 프로그램

JavaFX 데스크톱 앱의 첫 프로토타입입니다. 8~9주 개발·부산 한정 출시를 목표로 합니다. Java에서 예산·인원·원형 반경·카테고리 조건을 검사하고 최대 3개 코스를 추천합니다.

## 실행

- IntelliJ에서 Gradle 프로젝트로 열고 Project SDK 및 Gradle JVM에 Temurin 21을 지정합니다.
- Windows: `./gradlew.bat run`
- 테스트: `./gradlew.bat test`
- Scene Builder에서 `src/main/resources/com/datecourse/view/main.fxml`을 엽니다.
- Java 21 바이트코드를 생성하도록 `options.release = 21`을 설정했습니다. 도구 체인의 JDK 21 설치 자체를 자동 수행하지는 않습니다.

## 현재 동작

- 부산 서면 주변 좌표에 배치한 가상 장소 9곳. 실제 상호·가격·평점이 아니며 외부 API나 DB 연결이 필요 없습니다.
- 총예산은 전체 인원의 장소 이용 비용 합계입니다. 교통비·주차비 등은 제외합니다.
- 선택한 카테고리마다 1곳을 방문하며 화면에서는 식사 → 카페 → 문화 → 오락 순서를 사용합니다.
- 모든 장소가 입력한 중심점의 반경 안에 있어야 합니다.
- 가격 구간의 상한 합계가 예산 이하인 코스를 검색합니다. 추정 구간이므로 실제 지출을 보장하지 않습니다.
- 보정 평점·직선 이동거리·추정 가격 여부로 순위를 매기고 선택한 결과를 진하게 표시합니다.
- 카테고리별 최대 20개 후보 안에서 탐색합니다. 전체 장소 집합의 전역 최적해를 보장하지 않습니다.
- 계산은 JavaFX `Task`로 백그라운드에서 수행합니다.

지도, 로그인, 저장·공유, 커뮤니티, 피드백 처리, 관리자 화면, Aiven 연결은 아직 구현하지 않았습니다. 구현 범위·분담·서버 및 데이터 설계는 [개발 설계](docs/IMPLEMENTATION_PLAN.md)를 참고하세요.

## 구조

| 위치 | 역할 |
| --- | --- |
| `domain` | 불변 장소·요청·코스 모델, 거리·비용 계산 |
| `service` | UI·DB·API와 독립적인 추천 알고리즘 |
| `data/DemoPlaces` | 가상 장소 공급원; 실제 데이터 공급 계층으로 교체 예정 |
| `controller` | 입력 검증, 비동기 실행, 화면 상태 변경 |
| `src/main/resources/com/datecourse/view` | Scene Builder용 FXML |
| `src/test` | 추천 규칙 및 경계값 검증 |
