# 이전 장소 시연 코드·자료 보관

현재 앱은 DB의 운영 장소 목록 하나만 사용. 기본 오프라인 적재·자료 검사는 `data/places/expansion/current.json`의 장소·속성 쌍 사용.

- `src/`: 시연 저장소 2개, 외부 ID 파일럿 연결표·전용 검사, 파일럿·빈 지도 전용 실행 코드와 이전 검사 원본. 기본 Java 소스셋에서 제외.
- `data/places/demo`: 이전 9곳·386곳 목록과 당시 선정·검증 기록.
- `data/places/pilot`: 외부 장소 ID 대조 원본.
- `data/places/appeal/busan-2026-11-14`: 당시 공공 속성·근거 자료.
- `manifest.json`: 원래 경로와 보관 파일 54개의 SHA-256. 원본 바이트 유지.

역사적 확장·보존 검사는 이 보관 경로를 명시적으로 읽음. 관련 Python 재현 도구도 보관 자료를 참조. 운영 장소 ID·가격·회원·저장 코스·DB는 이번 작업에서 변경하지 않음. 운영 자료에 남아 있는 `DCA-DEMO-` 식별자 접두어는 저장 스냅샷과의 동일성 보존을 위해 유지.

일반 JAR에는 시연 장소 리소스·시연 저장소·보관 코드가 포함되지 않음. 알고리즘 검사의 작은 메모리 입력은 실제 자료와 구분한 검증용 입력으로 유지.
