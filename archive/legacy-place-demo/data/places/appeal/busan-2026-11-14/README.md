태그는 중복될 수 있습니다. 거리 태그는 출입구 접근성·횡단보도·고저차·실제 보행시간을 보장하지 않습니다. 특히 역 자료는 오래된 행이 섞여 있어 기준일을 보존합니다. 500m/200m는 제안한 초기 기준이며 사용자 선호 설정으로 확정한 값은 아닙니다.

최근접 시설 이름·ID·좌표 근거·기준일과 직선거리는 `demo_nearest_transit.csv`에 있습니다. 예를 들어 대모골은 서면역 역사 좌표까지 약 163m, 부전시장입구 정류장까지 약 57m입니다. 도보 거리·시간으로 표기하면 안 됩니다.

서면 주변은 대중교통 밀도가 높아 넓은 반경에서는 대부분 해당합니다. 역 100/200/300/500m 이내는 각각 6/66/99/118곳, 정류장 50/100/150/200m 이내는 각각 32/107/121/126곳입니다. 차별성을 위해 단순 ‘가까움’보다 실제 거리·현재 코스와의 이동 거리를 추천 이유에 쓰는 편이 유용합니다.

## 추가 시설 사실과 제한

`additional_facility_facts.json`에는 7개 사실을 별도로 보관합니다. 공원·문화시설 원문의 화장실/주차 정보와 증권박물관 무료 관람·무료 오디오가이드입니다. 오디오가이드는 신분증 보관 등 이용조건이 있고 주차 요금은 확인하지 않았습니다. 현행 Java PlaceTag에 없는 항목도 있어 앱 태그로 자동 수입하면 안 됩니다.

KT&G 상상마당 부산은 전시별로 요금이 다를 수 있고 확보된 표준자료에는 성인 15,000원으로 기록되어 있습니다. 과거 무료 전시 검색 결과만으로 시설 전체를 무료라고 표시하지 않았습니다. 공원·도서관이라는 분류만으로 무료나 조용함을 추정하지 않았습니다. 분위기·전망·데이트 적합성 같은 주관적 평가는 확보하지 않았습니다.

## 파일

- `raw/busan_bus_stops.csv`: 부산 정류장 원문 행, UTF-8 BOM으로 변환. 전국 다운로드 원본은 build 캐시에 보관.
- `raw/busan_railway_stations.csv`: 부산 주소의 역사 원문 행, Excel 일련번호/날짜 문자열은 ISO 날짜로 정리.
- `raw/national_railway_original.xlsx`: 제공기관이 배포한 XLSX 원본.
- `raw/busanjin_model_restaurants_cp949.csv`: 43행 원본 바이트 그대로 보관.
- `busanjin_model_restaurants.csv`: 모범음식점의 상호·주소·업종·주된 음식·전화·기준일을 읽기 쉬운 UTF-8 CSV로 정리.
- `designation_links.csv`: 기존 착한가격 연결 900건 + 신규 모범음식점 연결 32건. 지정별 행이며 고유 장소 합계와 다름.
- `designation_review_needed.json`: 이름·주소 유일 일치로 연결하지 못한 모범음식점 11행.
- `demo_appeal_facts.json`: 현재 127곳에 연결한 태그. 원본 시연 데이터는 변경하지 않음.
- `demo_nearest_transit.csv`: 최근접 시설 및 거리·기준일.
- `threshold_comparison.json`: 거리 기준별 해당 수.
- `sources.json`: 출처·공개 다운로드 URL·데이터셋 메타데이터·다운로드 체크섬.
- `checksums.json`: 입력 자료와 산출물의 SHA-256. 시연 데이터가 바뀌면 재매칭 필요.
- `summary.json`: 집계 결과.

## 재생성·검증

Python 표준 라이브러리만 사용합니다. `python tools/collect_busan_appeal_data.py`로 해당 스냅샷을 다시 만들 수 있습니다. 내려받은 파일은 `build/appeal-data-fetch`에 재사용하므로 새 기준일 수집 시에는 캐시·출력 경로·기준일을 함께 갱신해야 합니다. 배포 파일 구조가 바뀌거나 다운로드가 거절되면 오류로 멈추며 로그인을 우회하지 않습니다.

검증 명령: `python -m unittest discover -s tools -p test_collect_busan_appeal_data.py -v`

입력·출력 체크섬, 장소 ID 중복, 태그 중복, 지점명·건물번호 구분, 혼합 Excel 날짜, 좌표 범위, 최근접 시설 참조와 거리 단위 검증 4개 테스트를 통과했습니다. 현재 앱 Java 코드·DB·UI는 변경하지 않았습니다.
