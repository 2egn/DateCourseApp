# 보관 자료

현재 앱과 연결되지 않았지만 참고·복원 가치가 있는 파일을 보관한다. Gradle의 기본 소스·리소스 경로 밖이므로 앱 빌드와 JAR에 포함되지 않는다.

- [legacy-ui](legacy-ui/README.md): 가짜 관리자·커뮤니티·추천 코스 편집 예제와 관련 모델·자료·검사.
- [빈 DB 백업 정리](db-schema/2026-11-24-empty-backups/README.md): 승인한 빈 백업 8개의 재생성 SQL과 운영 검증 기록.
- 이전 문서 보관소 `docs/archive/`는 기존 링크를 유지한다. 운영 데이터·SQL·검증 기록은 원래 위치에 유지한다.

복원할 때는 해당 묶음의 안내와 `inventory.json`을 먼저 확인한다. 보관 자료를 운영 기능으로 간주하거나 archive 전체를 앱 소스로 등록하지 않는다.
