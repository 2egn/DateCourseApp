처음 한 번 설정하고, 문서와 할 일을 대화로 찾아보세요.

읽기 전용

3단계로 연결하기

별도 키 발급 없음

  1. Codex에서 서버 추가

    설정 → MCP 서버 → 서버 추가를 열고 아래 값을 넣으세요. 연결 유형은 Streamable HTTP예요.

    이름datecourseapp-team
    주소https://datecourseapp-team-docs.ate-ourse-pp.workers.dev/mcp

  2. 저장하고 GitHub로 인증

    저장 후 Restart(재시작)가 보이면 누르고, 서버의 Authenticate(인증)를 선택하세요. 브라우저에서 GitHub 로그인 후 읽기 전용 연결 허용을 누르면 끝이에요.

    DateCourseApp 저장소에 초대된 GitHub 계정으로 로그인해 주세요.

  3. 새 대화에서 확인

    아래 질문을 Codex에 붙여넣으세요. 계정과 실제 할 일이 나오면 연결된 거예요.

    datecourseapp-team 연결 상태를 확인하고, 작업 보드에서 중요도가 높은 미완료 작업 3개를 출처 링크와 함께 알려줘.

연결 정보를 확인하고 있어요…

이 브라우저에서 로그인한 계정의 연결을 확인해요.

설정 메뉴가 다르거나 연결이 안 될 때

터미널에서 아래 두 명령을 차례로 실행해도 돼요. codex 명령을 찾지 못하면 앱의 설정 방법을 사용하세요.

codex mcp add datecourseapp-team --url https://datecourseapp-team-docs.ate-ourse-pp.workers.dev/mcp
codex mcp login datecourseapp-team
  • 도구가 안 보이면: 연결을 켜고 새 대화를 열어 주세요. /mcp를 지원하는 화면에서는 서버 목록도 확인할 수 있어요.
  • 로그인이 만료되면: 서버의 인증을 다시 눌러 주세요. 연결은 최대 8시간 동안 유지돼요.
  • 권한이 없다고 나오면: 저장소 초대를 수락했는지, 다른 GitHub 계정으로 로그인하지 않았는지 확인하세요.
  • 연결됨인데 답변에 문서가 없으면: “datecourseapp-team 도구로 검색해줘”라고 요청하세요.
