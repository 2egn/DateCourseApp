작업 보드

무엇을 만들고, 무엇을 확인해야 하는지 한눈에 봐요.

처음이라면? 보드 읽는 법과 어려운 용어 보기

이렇게 사용해요

  1. 분야와 중요도로 관심 있는 작업을 찾아요. 각 열에서는 중요도가 높은 작업이 먼저 보여요.
  2. 카드 제목을 누르면 자세한 설명과 완료 확인 방법을 읽거나 수정할 수 있어요.
  3. 먼저 할 일이 있으면 그 작업부터 끝내요. 작업 이름을 누르면 해당 카드를 열 수 있어요.
  4. 시작하면 진행 중, 만들고 확인할 때는 동작 확인 중, 확인까지 끝나면 완료로 바꿔요.

중요도의 기준은 과제의 핵심 기능을 시연하고 코드를 설명하는 데 얼마나 필요한지예요. 높음은 필수 시연 흐름, 보통은 시연 보완, 낮음은 선택·후속 작업이에요. 출시 수준의 모든 예외 대응은 목표에 포함하지 않아요. 커뮤니티·관리자가 평가 항목이면 해당 작업의 중요도를 높여요.

보관함은 삭제가 아니에요. 지금 목록에서 빼 둔 작업을 나중에 다시 볼 수 있어요.
