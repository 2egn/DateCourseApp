## 구현 범위

공공자료 중심의 영구 장소 정보, 외부 연결의 검토 상태, 조회 시점의 외부 상세 정보를 분리했다. 기존 화면과 코스 저장 형식은 호환 생성자 및 누락 필드 기본값을 통해 유지한다.

| 모델 | 역할 |
| --- | --- |
| Place | 앱의 기존 장소 ID·기본 정보·코스 비용 표현 |
| PlaceDetails | 영구 출처·태그·속성 근거·외부 연결·기본 항목별 근거 |
| SourceEvidence | 근거 종류, 설명, URL, 자료 기준일, 확인/계산일 |
| PlaceAttributeFact / FactState | 속성별 가능·불가능·미확인과 근거 |
| ExternalPlaceLink | 제공자 ID, API 신뢰도, 검토 상태, 가게/주소 구분, 검토 기록 |
| PriceEstimate | 기존 1인/음료/입장 단위의 공공 참고·추정·관리자 검토 금액 |
| ProviderPriceRange | 외부 제공 통화별 가격 범위. 코스 예산 변환 기능 없음 |
| ExternalPlaceSnapshot | 검토된 외부 연결에서 얻은 일회 조회 정보. 메모리 전용 |

## 근거와 상태

- 이름·주소·세부 업종·위치는 PlaceDetails.fieldEvidence에서 별도 관리한다. 가격은 PriceEstimate, 시설 속성은 PlaceAttributeFact가 근거를 가진다.
- 근거가 없는 과거 기본 항목은 SourceEvidence.UNKNOWN이다. 기존의 외부 ID만으로 연결 확인을 주장하지 않는다.
- AVAILABLE / UNAVAILABLE / UNKNOWN을 구분한다. 속성이 없으면 UNKNOWN이다. 명시적으로 확인한 긍정/부정 값에는 근거가 필요하다.
- 기존 5개 태그는 호환 뷰로 유지한다. 새 typed 속성과 기존 태그가 서로 반대 상태를 표현하면 생성 시 거부한다.
- Google 제공 상세 속성은 영구 PlaceDetails의 속성/항목 근거로 넣을 수 없다. 공공 지정 태그는 Google 가격 수준에서 추론하지 않는다.
- SourceEvidence.referenceDate는 원본 자료 기준일, checkedAt은 검토 또는 계산일이다. 교통 태그는 오래된 정류장/역 자료를 최근 계산했다고 해서 원본까지 최신으로 보이지 않게 한다.

## 외부 연결

- confidence HIGH는 reviewStatus CONFIRMED와 독립적이다. HIGH여도 주소 대상이거나 검토 전이면 사용할 수 없다.
- CONFIRMED에는 VENUE 대상, 대조 방법, UTC 확인 시각, 검토 설명이 필요하다. MEDIUM도 별도의 동일성 검증을 통과하면 확인 가능하다.
- 기존 JSON의 externalIds.google은 NEEDS_REVIEW, entityKind UNKNOWN으로 읽는다. identityCheckedAt만으로 자동 승인하지 않는다.
- PlaceBindingCatalog.reviewedGoogleLink는 기존 데이터 지문·버전별 규칙·방문 적합성 검사를 통과한 연결표에서 확인된 연결을 반환한다. Resolution confidence가 없는 기존 자료에는 UNSPECIFIED를 사용한다.
- 연결표 어댑터는 디스크 기반 검증용이다. 앱의 11개 과거 Google ID를 모두 승인해 패키징하지 않았다. 표시 기능을 연결할 때에는 검증된 링크를 명시적으로 사용해야 한다.
- 이름·주소 정정 승인 시 기존 링크는 NEEDS_REVIEW가 된다. 이미 REJECTED인 링크는 거절 상태를 유지한다. 가격/업종 수정만으로는 장소 동일성 연결을 무효화하지 않는다.

## 외부 상세 값

ExternalPlaceSnapshot은 검토 완료 링크에서만 생성된다. 평점과 평가 수는 null을 허용하여 미확인과 0을 구분한다. 가격 범위는 별도 ProviderPriceRange로 표현한다.

영업 구간은 절대 시각으로 표현한다. 조회된 영업 구간 안이면 AVAILABLE이고 그 밖이면 UNKNOWN이다. 일부 구간만 받은 상태에서 폐점이라고 단정하지 않는다. 브레이크타임, 예외 영업시간, 예약한 날짜의 도착 시각은 향후 제공자 어댑터에서 반영해야 한다.

이 타입은 Jackson으로 루트/중첩 JSON 저장을 시도하면 예외를 던진다. toString에도 가격·평가·영업시간을 출력하지 않는다. 이는 앱 내 저장 실수를 줄이는 방어이며 임의로 다른 타입에 복사하는 행위까지 통제하는 경계는 아니다.

실시간 Google 호출, Places UI Kit 렌더링, WebView 호환성, 조회 실패 UI는 이번 모델 작업에 포함하지 않았다. 비Google 지도와 Google 콘텐츠의 표시·저장 조건을 확인한 뒤 별도 어댑터로 연결한다. 이번 작업 중 추가 API 호출은 없다.

## 공공자료 적재

PublicDemoPlaceRepository는 PublicPlaceFacts를 통해 기존 127개 장소에 공공 속성 자료를 연결한다. Gradle 리소스에 demo_appeal_facts.json만 추가하며 대형 원본 파일은 패키징하지 않는다.

원본 JSON은 체크아웃 환경의 줄바꿈 변환으로 지문이 바뀌지 않도록 LF로 고정한다.

적재기는 다음을 검증한다.

1. 스키마 버전, 원본 장소 JSON의 SHA-256 일치.
2. 전체 장소 수·내부 ID·공공 ID 일치, 중복 또는 누락 없음.
3. 지원 태그, 중복 태그, 근거·출처·유효 날짜.
4. 교통 접근성 계산일 존재, 유료 가격과 무료입장 태그의 충돌 없음.

현재 공공 태그는 착한가격 20곳, 모범음식점 2곳, 역 가까움 118곳, 정류장 가까움 126곳, 무료입장 1곳이다. 교통 근접도는 직선거리 기준이며 출입구나 실제 도보 시간을 뜻하지 않는다. 가격과 좌표 자체는 이번 적재로 변경하지 않는다.

후속 운영 적재 작업으로 127곳을 새 카탈로그에 적재했다. 기존 data_records 전역 번호를 사용하고 원본 통합 자료는 유지한다. 카탈로그가 있는 DB 모드는 활성 카탈로그를 읽는다. 상세 규칙과 실제 재적재 결과는 `docs/place-catalog-import-2026-11-15.md`를 참고한다.

## 정정 제보와 저장 호환

기존 제보 → 관리자 검토 → override 적용 흐름을 유지한다. 승인된 이름/주소/업종에는 ADMIN_REVIEW 근거가 남고, 가격은 기존 ADMIN_REVIEWED 표현을 사용한다. 승인 전에는 장소가 바뀌지 않는다.

유료 가격으로 정정하면 기존 무료입장 태그와 typed 사실을 함께 제거한다. 다른 속성과 근거는 보존한다. 주소가 바뀌어도 기존 좌표를 자동 추측하여 변경하지 않으며 외부 연결을 재검토 상태로 전환한다.

기존 저장 코스는 스냅샷을 유지하고 사용자가 명시적으로 수정 저장한 내용에만 최신 overlay가 반영된다. 기존 JSON에는 추가 필드가 없어도 읽을 수 있다. 신규 영구 모델은 JSON으로 round-trip이 가능하고 조회용 외부 스냅샷은 저장할 수 없다.

## 검증

전체 Gradle 테스트 230개 통과, 실패/오류/건너뜀 0. JAR 패키징 성공.

새 검증은 13개: 상태와 근거, 날짜, 주소 대상의 승인 거부, HIGH와 승인 분리, 과거 JSON 호환, 외부 값 저장 방지, 공공자료 지문/ID/날짜/태그 검증, 기존 가격·좌표 보존, 승인 연결표 어댑터, 관리자 주소 정정과 무료입장 정정의 회귀를 포함한다.
