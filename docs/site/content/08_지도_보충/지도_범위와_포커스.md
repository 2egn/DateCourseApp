장소 선택과 이동 경로 안내를 구분하고, 현재 작업에 맞춰 지도를 부드럽게 맞춰요.

| 조작 | 표시·포커스 |
|---|---|
| 출발지 선택 | 선택 위치와 전체 범위 |
| 원 테두리 호버 | 전체 허용 범위 또는 다음 장소·편집 구간 범위와 반경 |
| 장소 추가 | 이전 장소 → 새 구간 → 추가 장소 |
| 구간 반경 수정 | 선택 구간의 이전 장소를 중심으로 초록 원 이동 |
| 다음 장소 조건으로 전환 | 마지막 장소를 다음 검색 중심으로 복원 |
| 전체 코스 | 출발지와 선택한 장소 전체 |
| 장소 핀 클릭 | 장소 상세 카드. 경로 선택으로 처리하지 않음 |
| 경로선·번호 호버 / 클릭 | 요약 / 상세 이동 안내 |

상시 범례는 제거했어요. 원 내부나 드래그 중에는 범위 안내를 띄우지 않고, 핀·경로 팝업을 우선해요. 두 원이 겹치면 가까운 테두리를 선택하며 같은 거리에서는 다음 장소 범위를 먼저 안내해요.

<details>
<summary>변경 코드와 유지할 규칙</summary>

- `PlannerMap`: `presentCandidates()`, `fitCourse()`, `fitLeg()`, `ensureRangesVisible()`로 표시 의도를 전달해요.
- `map.js`: 현재 중심·반경과 투영 좌표로 테두리 근처를 판정해요. 화면 배율이 바뀌어도 마우스 인식 폭을 유지해요.
- `camera-motion.js`, `CameraMotionPolicy`: 가장 최근 목표를 우선하고 직접 지도 조작 시 대기 이동을 취소해요.
- `instant-zoom.js`: 현재 기본은 정수 레벨 SDK 확대예요. 실험적인 추가 배율 확대는 기본값이 아니에요.

범위는 직선 조건이며 도로 거리·실제 이동시간과 같지 않아요. 수단별 최대 반경은 `TravelMode`를 기준으로 해요.

</details>
