부산 메뉴별 외식비와 커피 전문점 조사값으로 추정을 보완해요. 매장 실값과 통계 추정은 구분하고, 미확인은 무료로 바꾸지 않아요.

운영 857곳 가격을 갱신했고 장소 수는 2,040곳이에요. 사용자·저장 코스·관리자 정정 등 17개 테이블과 장소 번호를 보존했으며 반복 적재도 변경이 없었어요. Java 368개(유지보수 3개 포함), Python 30개, 오프라인 추천 240개를 검증했어요.

- `supplement_place_prices.choose_price()`: 매장·지역·메뉴·단위에 맞는 근거 선택.
- `PriceEstimate.briefBasis()`: ‘부산 지역별 외식비’, ‘외식업체 조사’로 간결하게 표시.
- `PlaceCatalogRepository.validatePriceUpdate()`: 장소 ID·가격 외 필드 보존 확인.
- `ExpansionAudit`: 운영 기준본 대조, 사용자 데이터 보존·반복 적재 검증.

<summary>이번 적용 범위와 한계</summary>

2,040곳 중 메뉴가 맞는 37곳과 카페 820곳의 추정을 변경해요. 카페는 전국 커피 전문점 조사 530사례 평균 4,118원을 대표 메뉴 1잔으로 가정해요. 매장별 참고 가격 17곳은 유지하고, 기존 공공 메뉴의 제공량 미확인은 실값으로 승격하지 않아요.

같은 메뉴의 부산 통계가 없는 기존 추정은 유지해요. 착한가격 표본 편향이 전부 해소된 상태는 아니에요. 자료는 지역·메뉴의 참고 수준이며 실제 메뉴 구성·결제액을 보장하지 않아요.

출처·재현 명령·운영 결과는 저장소 `data/places/pricing/2026-11-24/`에 있어요. 이전 모의 추천의 성공률은 변경 전 가격 기준이에요.
