# 문서 읽는 법

궁금한 기능 하나를 골라 **사용자 동작 → 예시 → 기술과 이유 → 핵심 코드** 순서로 읽습니다.

## 기능부터 찾기

[[기능별_구현/목차|기능별 목차]]에서 회원·편집·추천·가격·지도·경로·저장·제보 등 필요한 문서만 엽니다. 코드 연결 표는 필요한 때 펼칩니다.

## 근거를 구분하기

가상 상황은 이해를 위한 예시입니다. 테스트·실제 공급사·운영 DB 검증 결과와 다릅니다. source_commit·source_sha256은 원래 발췌의 근거이며 reviewed_commit·reviewed_at은 나중에 확인한 시점입니다.

[[99_이전_문서/목차|이전 문서]]는 현재 설명으로 사용하지 않습니다. 같은 클래스가 지금도 있어도 발췌가 다르면 이전 버전으로 표시합니다. 분리한 발췌와 당시 해시는 보존합니다.
