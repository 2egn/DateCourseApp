화면별 폴더에서 관련 클래스를 찾고, Java와 FXML은 같은 패키지 경로로 대응해요. Gradle의 `src/main/java`·`src/main/resources` 구분은 유지해요. [[09_구조와_검토/순서_넘버링과_미사용_정리_2026_11_24|순번·보관·삭제 내역]]을 함께 확인하세요.

| 화면 | Java 패키지 | 컨트롤러 · FXML |
|---|---|---|
| 코스 구성 | `com.datecourse.page._01step_planner` | `CoursePlannerController` · `condition-view.fxml` |
| 코스 편집 | `com.datecourse.page._02step_editor` | `CourseEditorController` · `route-editor-view.fxml` |
| 저장한 코스 | `com.datecourse.page._03step_saved` | `SavedCourseController` · `saved-course-view.fxml` |
| 내 페이지 | `com.datecourse.page.account` | `MyPageController` · `my-page-view.fxml` |
| 정보 정정 검토 | `com.datecourse.page.review` | `InformationReviewController` · `information-review-view.fxml` |

- `ConditionController` → `CoursePlannerController`: 공통 조건과 확정 코스·화면 이동 조율.
- `RouteEditorController` → `CourseEditorController`: 방문 장소·순서·조건 편집.
- `PlannerMap` → `page.common.map.CourseMapView`: 여러 페이지의 공통 지도.
- `MapBridge` → `page.common.map.MapEventBridge`: 지도와 Java의 이벤트 연결.
- 기존 `CourseEditController` → `archive/legacy-ui`의 `RecommendedCourseEditorController`: 추천 코스 편집 시연. 통합 앱의 편집과 구분해요.

<details>
<summary>공통 코드와 경로 변경</summary>

`BasePageController`, `PageFeedback`, `NumberStepper`, `TmapSettingsDialog`는 `page.common`에 있어요. `MapViewportLifecycle`은 지도 내부 구현으로 `page.common.map`에, 정보 정정 제보 창은 `page._01step_planner`에, 이미지 미리보기 창은 `page._03step_saved`에 둬요.

FXML은 `src/main/resources/com/datecourse/page/<페이지>/`에 있어요. 추천 코스 편집·관리자·커뮤니티 예제는 `archive/legacy-ui`에 보관했어요. 공통 스타일은 리소스 루트, 웹 지도 자료는 `resources/map`에 유지해요.

`fx:controller`, Java의 로딩 경로, `fx:include`, 공통 스타일 참조와 테스트를 함께 갱신했어요. FXML 필드·이벤트 이름과 `javaMapBridge` 등 JavaScript 계약, `RoutePlan`·`TravelRoute` 모델은 유지해요. 새 상속 계층이나 화면 전환 프레임워크는 추가하지 않았어요.

</details>

<details>
<summary>검증과 과거 문서</summary>

순번 정리 후 기본 Java 검사는 368개(유지보수 3개 포함)예요. 예제 전용 2개는 archive에 보관했어요. 지도·후보·편집·저장·이미지 요청 검사와 별도 빈 출력 경로의 테스트·JAR 패키징을 확인했어요. 정리 전 JAR의 FXML 8개가 새 컨트롤러·포함 화면·공통 스타일을 참조하고 이전 경로가 없는지 검사했어요. 이동한 17개 클래스의 메서드 본문도 이름·경로·접근 범위 외에는 유지했어요. 실제 공급사 호출·운영 DB 변경은 이 경로 변경에 포함하지 않아요.

이전 이름의 클래스 노트는 링크를 유지하고 상단 `current_source`로 현재 위치를 안내해요. `source_commit`·`source_sha256`·과거 원본 링크와 코드 발췌는 당시 기록으로 보존해요. 사이트 원본 수정과 실제 배포는 별개예요.

</details>
