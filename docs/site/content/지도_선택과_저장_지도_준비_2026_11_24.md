기능 브랜치의 지도·저장 화면 개선이에요. 지도 준비 여부는 세션 안에서만 기억하고 추가 DB 구조를 만들지 않아요.

## 화면에서 달라지는 점

- 상단의 코스 만들기·저장한 코스 버튼은 현재 화면을 어두운 배경으로 표시해요.
- 장소·구간 상세 카드는 왼쪽에서 열어요. 경로 클릭은 오른쪽 구간 안내도 함께 열어요.
- 호버는 짧은 요약 한 개만 보여주고, 안내 위로 마우스를 옮겨도 유지하지 않아요.
- 마커·경로는 기본 반투명이고 호버·명시적인 선택 포커스 동안 불투명해요. 포커스가 이동하면 이전 요소의 강조가 풀려요. 마커가 경로보다 입력을 우선해요.
- 이미지 전용 코스에도 상단 이미지·지도 전환이 보여요. 중복된 하단 지도 보기 버튼은 제거했어요.
- 목록·상세 제목 아래·장소 표에 이동수단과 조회된 시간을 표시해요. 경로 미조회는 ‘조회 전’으로 구분해요.

## 저장 지도 흐름

`이미지 → 지도 선택 → 지도 불러오기 → SDK 준비 완료 → 세션에 기록` 순서예요. 같은 로그인 안에서는 이미 불러온 코스의 지도 탭을 바로 열어요. 실제 경로 API는 여전히 이동 경로 조회 버튼으로 요청해요.

| 구현 | 책임 |
|---|---|
| `SavedCourseController.onSelectMap/onLoadMap/rememberMapPrepared` | 전환·명시적 불러오기·완료 상태 갱신 |
| `UserContext.isMapPrepared/markMapPrepared` | 현재 회원의 코스 ID 집합으로 불러온 여부 기억 |
| `UserContext.invalidateCourses/close` | 코스 목록 갱신·로그아웃 시 상태 제거 |

새 로그인이나 앱 재실행에서는 다시 불러오기를 선택해요. 새 테이블·SQL·해시 비교는 필요하지 않아요. 저장 코스·이미지·이동수단의 기존 DB 구조는 유지해요.

## Java와 검증

컴파일·검사·Gradle 앱 실행은 설치된 JDK 21 toolchain을 사용하고 `--release 21`을 유지해요. JavaFX 21과 명시된 의존성 버전을 사용해요. IDE 직접 실행의 SDK도 21로 맞춰요. IDE 내부 등 일반 검색 위치 밖의 JDK 21은 `JAVA_HOME` 또는 `JDK21_HOME`에 설치 위치를 지정해요. JDK 25로 Gradle을 시작해도 `JDK21_HOME`의 21을 컴파일·검사·앱 실행에 선택하는지 확인했어요.

JavaFX WebView에서 실제 지도 스크립트와 모의 SDK를 연결해 단일 호버·마커 우선순위·선택 이동·왼쪽 카드의 긴 안내를 검사해요. 세션 검사로 코스별 상태의 보존·목록 무효화·로그아웃 초기화·다른 회원과 새 로그인 사이의 분리를 확인해요. 저장 화면은 이미지 전용 전환과 명시적 불러오기, 재선택 시 세션 상태 반영을 검사해요. 실제 공급사·운영 DB 변경·운영 배포는 실행하지 않아요.

검증 결과: Java 전체 379개(앱 376·선택 유지보수 3), 보관 예제 2개 통과. JAR 생성과 지도 JavaScript 문법 검사, 문서 145개 로컬 빌드도 통과했어요.
