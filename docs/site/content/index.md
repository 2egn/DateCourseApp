처음 앱을 실행하거나 Java 코드를 공부하는 팀원을 위한 안내예요. 사용자가 화면에서 하는 일을 먼저 이해하고, 그 일을 담당하는 코드로 이어서 읽을 수 있게 정리했어요.

팀원 API 설정은 [[공통_접속_키|공통 접속 키 하나로 설정하기]]를 참고하세요.

## 어디서부터 읽으면 좋을까요?

1. **앱을 처음 켜 보려면** [[실행_및_테스트|처음 실행하기와 테스트]]를 읽으세요. 프로젝트를 내려받은 PC에서 Java·DB·지도 설정을 준비하는 순서예요.
2. **코드 용어가 낯설다면** [[문서_읽는법|문서 읽는 법]]부터 보세요. 클래스·메서드·콜백·JSON 같은 말을 이 앱의 예시로 설명해요.
3. **앱 전체가 어떻게 이어지는지 보려면** [[전체_동작_흐름|전체 동작 흐름]]을 읽으세요. 로그인에서 장소 추천·편집 완료까지 따라가요.
4. **담당 파일을 찾으려면** [[목차|클래스 목차]]를 여세요. 각 클래스 문서의 ‘사용 장면과 읽는 순서’부터 읽으면 돼요.

## 직접 눌러보며 이해하기

글로만 헷갈리는 부분은 문서 안의 설명용 그림을 조작해 볼 수 있어요. 실제 앱이나 작업 보드의 데이터는 바꾸지 않아요.

- [[02_화면/RouteEditorController|편집을 취소하면 원래 코스는 어떻게 될까요?]] — 원래 코스와 편집본을 나눠 비교해요.
- [[03_처리/NextPlaceService|두 거리 범위를 모두 만족하는 후보는 어디일까요?]] — 허용 거리를 바꿔 후보가 달라지는 모습을 봐요.
- [[02_화면/PlannerMap|이전 요청의 응답이 늦게 오면 어떻게 할까요?]] — 지금 선택한 장소의 결과만 남기는 이유를 확인해요.
- [[04_데이터/RoutePlan|1인 가격과 총금액은 어떻게 다를까요?]] — 인원을 바꾸며 금액 계산을 확인해요.

## 기능 하나를 따라 읽고 싶다면

**장소 한 곳을 추천받는 과정:** [[02_화면/RouteEditorController|편집 화면]] → [[03_처리/NextPlaceService|후보 고르기]] → [[04_데이터/Place|장소 정보]] → [[03_처리/RouteRangeValidator|거리 제한 확인]].

**지도와 Java가 연결되는 과정:** [[02_화면/PlannerMap|Java의 지도 담당자]] → [[08_지도_보충/map.js|웹 지도 표시]] → [[02_화면/MapBridge|지도 선택을 Java에 알리기]].

**가져다 쓴 도구가 궁금하다면:** [[라이브러리_사용_안내|라이브러리 사용 안내]]에서 각 도구가 필요한 이유와 사용 함수를 찾아보세요.
