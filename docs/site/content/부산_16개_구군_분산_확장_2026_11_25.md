구·군별 식사 150·카페 120·문화 30곳을 목표로 기존 500m 격자·업종 순환 정책을 적용했어요. 목표를 넘는 기존 지역은 유지하고 부족한 지역만 더했어요. 중구 문화는 추가 품질 검사를 통과한 후보가 없어 18곳을 유지했어요. 부산 전체 업소를 대표하는 통계 표본이나 구·군별 완전히 같은 개수를 뜻하지 않아요.

전체는 식사 2,800·카페 2,260·문화 568곳이에요. 가격은 참고 23·추정 3,092·미확인 2,513곳이며 신규 1,460곳의 통계 보완도 실제 매장 가격이 아니에요. 기존 공공 원본을 체크섬 검증 후 재사용했고 영업·현장 가격·지도 동일 장소를 새로 확인하지 않았어요.

Python 도구 32개와 Java 모의 코스 696개를 통과했어요. 세 활동 선택은 373→535, 이전 코스 조건 이탈·단계 감소는 0이에요. 실제 이동 경로 API나 사용자 완료율 검사는 아니에요.

선택 정책·출처·지문·운영 대조·재현 명령은 저장소 `data/places/expansion/busan-balanced-2026-11-25/README.md`에 정리했어요. 내장 시연 386곳과 테이블 구조는 바꾸지 않아요. 실행 중 앱은 장소 목록을 다시 읽거나 재시작해야 새 자료를 사용해요.
