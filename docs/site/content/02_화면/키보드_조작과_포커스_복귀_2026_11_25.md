title: 목록 키보드 조작과 포커스 복귀
reviewed_at: 2026-11-25
---

저장 장소 표와 편집의 내 코스 목록에 키보드 조작을 연결했어요. 기존 코스 편집·지도 불러오기 정책은 유지해요. 이번 개선은 기능 브랜치 작업이며 운영 master 배포와 구분해요.

| 화면 | 조작과 결과 |
|---|---|
| 저장 장소 표 | 방향키로 행을 고르고 Enter로 지도에서 봐요. 선택만으로 지도를 준비하거나 실제 이동 경로를 요청하지 않아요. |
| 이미지 전용 저장 코스 | Enter를 눌러도 지도 탭의 ‘지도 불러오기’를 먼저 눌러야 해요. 그동안 선택한 장소를 보관하고 지도를 연 뒤 포커스해요. |
| 편집 내 코스 | 후보 목록과 동일하게 Enter로 선택 장소의 상세를 열어요. 추가·삭제는 기존 명시적인 버튼을 사용해요. |
| 지도 상세 | 닫기·Esc로 닫으면 열었던 조작 위치로 돌아가요. 원래 요소가 사라졌다면 보이는 카드나 지도 영역으로 돌아가요. |
| 확대 이미지 | Enter/Space로 열고 Esc·닫기로 돌아가요. 확대 중 Tab/Shift+Tab이 뒤쪽 지도 버튼으로 빠지지 않아요. |
| 공통 버튼 | 포커스가 있는 버튼·전환 버튼·메뉴 버튼에 파란 표시를 더해요. 저장 표의 선택 행은 배경색으로 구분해요. |

`SavedCourseController.focusPlaceRow()`가 마우스·Enter의 공통 진입점이에요. 기존 미리보기 요청 번호·이미지 확인 상태·세션 준비 상태와 실제 경로 조회의 별도 동작을 보존해요. `CourseEditorController.configureEditorNavigation()`에 내 코스 Enter를 연결해요. `itinerary-rail.js`와 `map.html`은 상세·확대 창을 열기 전의 포커스를 기억해요. `MapEventBridge.onDetailClosed()`는 사용자가 상세를 닫은 사실만 JavaFX에 전달해요. `CourseMapView.showDetail()`이 지도 밖에서 상세를 연 조작 위치를 보관하고, 닫은 뒤 원래 목록·버튼으로 돌아가요. 다른 버튼으로 이동했거나 원래 화면이 숨겨졌거나 코스를 초기화했다면 포커스를 가져오지 않아요.

자동 검사는 실제 FXML·WebView에 모의 지도 SDK와 격리 DB를 사용해 방향키 선택, Enter, 명시적 불러오기, 확대 창의 Tab/Esc, 원래 요소 제거 후 복귀를 확인해요. 실제 공급사 호출·운영 DB 쓰기는 포함하지 않아요. Windows의 실제 Tab 이동·화면 배율·스크린리더 사용성은 수동 확인이 남아 있어요. 대시보드의 `KEYBOARD-UX-25` 수동 확인까지 완료했다고 표시하지 않아요.

검증 결과: 앱·선택 유지보수 Java 386개와 보관 UI 2개 통과, JAR 생성 완료.

추가 보강: 지도 밖 JavaFX 목록·버튼 복귀와 뒤늦은 닫기 콜백 차단도 검사했어요.

JavaFX 포커스 연결 추가 후 전체 앱·유지보수 Java 394개와 보관 UI 2개를 통과했고 JAR를 생성했어요.

이미지 확인이 늦은 뒤 이미지 없음이 확인되어 기존 지도를 바로 다시 사용할 때도, 기다리는 동안 선택한 장소의 포커스를 적용해요. 늦은 전체 코스 맞춤이 이 선택을 덮어쓰지 않도록 요청 번호를 유지해요.

열었던 버튼이 상세·확대 창을 보는 중 비활성화되어 포커스를 받을 수 없게 된 경우도 검사해요. 실제 포커스 이동 성공 여부를 확인하고, 실패하면 보이는 지도·이미지로 복귀해 닫힌 요소에 남지 않아요.

저장 장소 행은 기본(왼쪽) 클릭과 Enter로만 지도를 전환해요. 우클릭·가운데 클릭은 명시적 지도 불러오기 상태를 바꾸지 않아요.

편집의 내 코스는 실제 장소 행을 왼쪽 더블클릭할 때만 상세를 열어요. 빈 영역이나 우클릭 더블클릭으로 이전 선택의 상세를 열지 않아요. Enter와 별도 상세 버튼은 유지해요.

코스를 빠르게 바꾸거나 화면을 비울 때 이전 화면 전용 미리보기 변환을 취소하고 참조를 비워요. 공유 이미지 조회와 캐시는 유지하며, 이미 실행 중인 디코딩의 강제 종료와 구분해요. 이전 화면의 늦은 응답은 요청 번호로 계속 차단해요.
