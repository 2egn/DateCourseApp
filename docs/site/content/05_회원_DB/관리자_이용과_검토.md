회원 관리는 기존 로그인 창에서 열린다. 상단 로그아웃으로 로그인 화면에 돌아간다.

- 표는 이름, 이메일, 전화번호, 상태, 가입일 순서로 표시한다. 이메일·이름 검색과 열 정렬을 지원한다.
- 상태는 화면에서 정상/탈퇴로 표시하며, DB의 ACTIVE/INACTIVE 값은 유지한다.
- 회원을 선택하면 하단 편집란에 대상을 표시한다. 변경 저장 확인창에는 변경 전후 내용을 보여준다.
- 탈퇴와 영구 삭제도 대상 확인 후 실행한다. 정상 회원 또는 저장한 코스가 있는 탈퇴 회원은 영구 삭제하지 않는다.
- 작성 중 다른 회원 선택, 검색 또는 로그아웃/종료를 하면 저장하지 않은 변경을 버릴지 확인한다.
- 작업 중에는 검색·선택·편집을 잠근다. 탈퇴 처리는 상태만 바꾸고, 회원 정보 변경 여부를 DB에서 다시 비교한다.
- 저장 후 목록 조회만 실패한 경우 저장 완료와 목록 조회 실패를 구분해서 안내한다.

제보 검토는 접수 당시 정보와 현재 승인된 정정을 구분한다. 승인/반려 전에 대상·내용·메모를 확인한다.
승인 전 최신 정정과 다시 비교하므로 다른 검토에서 바뀐 값을 이전 화면의 값으로 덮어쓰지 않는다.
최신 정정은 관리자 승인 기록이며 외부 제공자의 실시간 조회 결과를 뜻하지 않는다.

검증: H2 격리 DB에서 수정/탈퇴/삭제 확인·취소, 미저장 편집 보호, 코스가 있는 회원 삭제 제한,
오래된 회원/정정 정보로 저장 차단, 실제 제보 승인 버튼 동작을 확인한다.
화면 시안은 테스트에서 build/ui-preview/admin-members.png 및 information-review.png로 생성한다.
실제 회원과 저장한 코스는 테스트에서 변경하지 않는다.
