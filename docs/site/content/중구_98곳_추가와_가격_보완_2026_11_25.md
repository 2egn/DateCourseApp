운영 공공 카탈로그에 중구 98곳을 더해 2,138곳으로 늘렸어요. 기존 2,040곳의 DB 번호·내용·가격·속성은 보존했어요. 내장 시연 386곳은 그대로예요. 실행 중 앱은 장소를 다시 읽거나 재시작한 뒤 새 목록을 사용해요.

| 항목 | 결과 |
|---|---|
| 새 장소 | 식사 40·카페 40·문화 18곳 |
| 새 가격 상태 | 통계 추정 56·미확인 42곳. 미확인을 무료로 바꾸지 않아요. |
| 전체 가격 상태 | 참고 17·추정 1,232·미확인 889곳 |
| 특징 | 새 장소 중 착한가격 공공 지정 연결 10·지하철 직선 기준 71·버스 정류장 직선 기준 83곳 |
| 보류 | 중복·좌표·자료 기준일 등의 검토가 필요한 신규 공공 ID 51개 제외 |
| 보호 | 회원·관리자·제보·정정·저장 코스·이미지 등 보호 테이블 9개와 기존 일반 데이터 행 보존 |
| 반복 적재 | 확장·가격 보완 모두 2,138곳 변경 없음 |

기존 공공 원본을 재사용해 500m 격자와 업종을 번갈아 선택했어요. 업체 영업·Google 동일 장소·현장 메뉴 가격을 새로 확인한 자료는 아니에요. 출입구·도보 동선도 별도 확인이 필요해요.

처음 확장한 뒤 새 카페에 이전 저가 표본 추정이 남는 것을 대조했고, 기존과 같은 가격 보완 규칙으로 신규 43곳만 갱신했어요. 지역 외식비 3·커피 조사 40곳이에요. 커피 4,118원/잔은 조사 기반 대표 메뉴 추정이며 매장 실값이 아니에요. 가격 외 필드와 기존 2,040곳은 그대로예요.

Python 도구 검사 32개를 통과했어요. 실제 Java 추천·가격·특징·반경으로 만든 312개 모의 코스에서 3개 활동 선택은 191→217, 단계 감소와 기존 코스 후보 이탈은 0이었어요. 고정 최근접 선택을 비교한 것이며 실제 이동 경로·사용자 완료율·추천 품질 점수가 아니에요.

현재 기준 파일 쌍은 저장소 `data/places/expansion/current.json`, 자료·출처·운영 결과는 `data/places/expansion/jung-gu-2026-11-25/`에서 관리해요. 최초 확장 입력은 `dbb2507`, 최종 가격 전용 보완은 `price-review.json`과 `price-import-verification.json`으로 구분해요. 테이블을 추가하거나 기존 공공 ID를 병합하지 않았어요.
