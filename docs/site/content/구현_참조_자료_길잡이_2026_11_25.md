자료는 소스 기준 a0d9436의 현재 구현을 설명해요. 전체 색인은 설정·Java·FXML·JS·CSS·SQL·도구·검사·자료·문서·보관 파일을 포함하며 개인 설정·비밀값·생성물·캐시는 제외해요. 핵심 기능 설명과 모든 본문을 개별 심층 감사한 것은 구분해요.

모델은 계획 RoutePlan과 실제 조회 TravelRoute를 분리하고, 가격의 미확인·무료·범위·추정을 구분해요. exact()는 범위 양 끝이 같다는 숫자 조건이지 메뉴 검증 완료가 아니에요. 추천은 전체/다음 반경·가격·유형·특징을 적용한 뒤 거리순 후보를 제공하며, 필터 뒤에 개수를 제한해요. 최적 코스·개인화 학습·실제 시간순 추천이라고 설명하지 않아요.

기능 문서는 예시·흐름도·확인 범위·한계와 함께 읽고, 클래스 색인은 필요한 코드만 찾는 데 사용해요. 시연 전용·보관 코드·오프라인 탐색은 일반 앱의 현재 기능과 구분해요. 원격 푸시·운영 사이트 배포는 이 문서 작성과 별도예요.
