작은 창의 정보 압축과 옅은 설명 글자를 개선한 기능 브랜치 작업이에요. 코스·지도·필터의 처리와 세션 상태는 유지해요.

| 화면·항목 | 현재 동작 |
|---|---|
| 편집 합계 | 보조 패널 폭 560px 미만에서는 이동수단·총 시간과 총 예상비용을 두 줄로 표시해요. 넓으면 기존 세 카드를 사용해요. |
| 정보 역할 | 합계는 상단에, 구간 시간·누적 시간은 장소 목록에 표시해요. 조회 중 문구 중복과 합계 반복을 줄였어요. |
| 저장 상세 표 | 상세 영역 900px 미만은 장소 표 → 요약 표 순서로 세로 배치하고 스크롤해요. 넓으면 두 표를 나란히 보여줘요. 장소 수가 적을 때 빈 표 높이를 줄여요. |
| 글자 | 공통 보조 문구를 13px와 더 진한 색으로 조정했어요. 지도 상세 본문도 13px·넓은 줄 간격으로 읽어요. |
| 목록 선택 | 편집 목록의 선택 행을 연한 버건디 배경과 왼쪽 진한 선으로 구분해요. |
| 긴 지도 상세 | 세로 스크롤바를 표시하고, 버튼 문구가 두 줄이어도 버튼 안에 들어오게 높이를 조절해요. |
| 알림 | 오른쪽 조건 패널을 가리지 않도록 왼쪽 하단, 하단 버튼 영역 위에 표시해요. |

## 주요 위치

- `CourseEditorController.configureResponsiveSummary`: 패널 폭에 따른 합계 전환.
- `SavedCourseController.configureResponsiveDetails/layoutDetailTables`: 정보 표의 폭·순서·높이 전환.
- `PageFeedback`: 알림 위치·기존 닫기/자동 사라짐 동작.
- `style.css`, `map/itinerary-rail.css`, `map/map.html`: 글자 대비·선택 표시·상세 스크롤과 테마.

## 검증 범위

JavaFX에서 작은 창과 넓은 창을 비교해 요약 전환·표 스크롤·버튼 영역과 장소명 폭을 확인해요. 실제 지도 스크립트를 모의 SDK로 실행해 긴 상세의 스크롤과 본문 크기를 확인해요. 최근 생성한 화면 캡처도 확인해요. 실제 지도 타일 위의 대비와 Windows 배율별 수동 시연은 별도예요. 운영 DB·API·사이트 배포 작업은 포함하지 않아요.
