---
title: JDK 21 자동 검색과 선택
reviewed_at: 2026-11-25
---

프로젝트의 컴파일·테스트·Gradle 앱 실행은 JDK 21을 사용해요. JDK 25 등 다른 버전이 함께 있어도 21 조건에 맞는 설치만 선택해요.

## 검색 범위

`gradle.properties`에서 Gradle의 기본 자동 검색을 켜고 다음 환경변수의 설치 경로를 후보에 추가해요.

| 설정 | 역할 |
|---|---|
| `org.gradle.java.installations.auto-detect=true` | 일반 설치 위치·지원되는 설치 도구·IDE 위치 등 Gradle 기본 검색 |
| `JDK21_HOME` | 일반 위치 밖에 설치한 JDK 21의 명시적 위치 |
| `JAVA_HOME_21_X64` | CI 등에서 제공하는 JDK 21 위치 |
| `JAVA_HOME` | 현재 기본 JDK 위치. 버전이 25라면 앱의 21 도구 후보로 선택되지 않음 |

환경변수의 나열 순서가 선택 우선순위는 아니에요. 모든 경로를 후보에 추가한 뒤 `build.gradle`의 Java 21 조건과 Gradle 선택 규칙을 적용해요. 여러 21 배포판 중 하나를 강제하지는 않아요. Gradle 자체를 시작하는 JDK와 앱 컴파일·검사·실행 JDK는 구분해요.

공유 파일에는 개인 PC의 설치 경로와 JDK 바이너리를 넣지 않아요. 임의 폴더·이름으로 압축 해제한 모든 JDK를 디스크 전체에서 검색하는 기능은 아니므로, 검색되지 않는 21은 `JDK21_HOME` 또는 개인 Gradle 설정의 `org.gradle.java.installations.paths`로 알려줘야 해요.

## 설치가 없는 경우의 자동 다운로드

`settings.gradle`의 Foojay resolver convention 1.0.0과 `auto-download=true`를 사용해요. 로컬 후보에 맞는 JDK 21이 없을 때만 현재 운영체제·CPU에 맞는 21을 Gradle 사용자 홈의 `jdks`에 받아요. 기본 위치는 `~/.gradle/jdks`이고 `GRADLE_USER_HOME` 설정이 있으면 그 아래에 보관해요.

설치된 21이 있으면 그 설치를 사용해요. 캐시된 JDK는 다른 빌드에서도 재사용해요. 처음 플러그인·JDK를 받는 시점에는 인터넷이 필요해요. 완전히 새 PC에서는 Gradle 자체를 시작할 JDK 17 이상이 먼저 있어야 해요. Gradle을 거치지 않는 IDE 직접 실행의 Project SDK는 여전히 21로 맞춰요.

배포판을 프로젝트에서 강제하지 않아 로컬의 다른 JDK 21도 사용할 수 있어요. 자동 다운로드는 설치 관리 방식이며 캐시된 JDK의 보안 업데이트를 자동으로 교체하는 기능은 아니에요.

플러그인은 [Gradle Plugin Portal](https://plugins.gradle.org/plugin/org.gradle.toolchains.foojay-resolver-convention)의 고정 버전을 사용해요.

## 확인 방법

`./gradlew.bat -q javaToolchains`로 발견된 JDK를 확인해요. IntelliJ는 Gradle 새로고침 후 다시 실행해요. IDE에서 Gradle을 통하지 않고 직접 실행한다면 Project SDK도 21로 지정해야 해요.

이 PC의 개인 Gradle 설정에는 CLion 내부의 JDK 21 경로를 등록했지만, 해당 경로는 저장소 변경에 포함하지 않아요.

선택·검색 방식은 [Gradle 공식 Toolchains 문서](https://docs.gradle.org/current/userguide/toolchains.html)를 참고해요.

## 검증 결과 · 2026-11-25

- 기존 설치를 검색하는 빌드에서는 JDK 캐시가 빈 상태로 유지됐고 컴파일·검사·실행 도구가 21을 선택했어요.
- 로컬 검색을 25만 보이도록 제한하고 캐시가 빈 조건에서 실제 JDK 21 다운로드를 확인했어요.
- 같은 조건에서 오프라인으로 캐시의 21을 재사용했고, 전체 Java 검사 384개·보관 예제 2개를 다시 실행해 통과했어요. JAR 생성도 통과했어요.
- 공유 설정에는 JDK 파일과 개인 설치 경로가 없어요. 실제 공급사·운영 DB 변경은 수행하지 않았어요.
