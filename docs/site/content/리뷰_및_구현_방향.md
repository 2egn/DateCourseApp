# 검토와 남은 확인

현재 기능 설명은 [[기능별_구현/목차|기능별 문서]]를 기준으로 읽습니다. 이미 대체된 제안·미구현 목록은 [[99_이전_문서/이전_안내/리뷰_및_구현_방향_2026_11_25|이전 검토]]로 분리했습니다.

## 마무리 확인

물리 키보드·마우스 연속 조작, 배율·모니터 이동, 느린 네트워크에서의 최종 사용 흐름을 확인합니다. 자동 검사 통과와 현장 확인을 구분합니다.

## 개선 후보

여러 앱에서 같은 코스를 편집할 때의 덮어쓰기, 긴 코스의 공급사 요청량, 실행 중 설정 캐시 갱신, 카탈로그 적재 성능·추적은 후속 검토 대상입니다. 현재 완료 기능으로 표시하지 않습니다.

추천은 조건에 맞는 후보를 제공하는 방식이며 전체 최적 시간·요금·만족도를 보장하지 않습니다. 가격·영업·분류 근거도 [[기능별_구현/03-recommendation|추천]]과 [[기능별_구현/04-price-and-models|가격·모델]]의 범위 안에서 설명합니다.
