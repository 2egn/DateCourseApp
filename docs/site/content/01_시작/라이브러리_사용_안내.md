화면·DB·JSON·지도에 필요한 기능을 라이브러리로 연결합니다. 구현 기준 d5659e3이며 버전은 현재 선언값입니다.

## 기술과 필요한 기능

| 기술 | 왜 사용하는가 | 실제 적용 |
|---|---|---|
| Java 21 · Gradle Wrapper | 빌드·검사·실행 환경 일치 | toolchain 21 · release 21 · Foojay 자동 준비 |
| JavaFX 21.0.13.1 · Swing | 회원 UI와 코스 화면 연결 | FXML · JFXPanel · WebView |
| Jackson 2.17.0 | JSON을 Java 모델과 연결 | API 응답 · DB payload · 지도 전달 값 |
| JDBC · Connector/J 8.3.0 | SQL 요청·바인딩·트랜잭션 | 회원·코스·카탈로그 Repository |
| HikariCP 7.1.0 | DB 연결 재사용·대기 제한 | 최대 2 · 최소 유휴 1 |
| 카카오 지도 SDK · TMAP/카카오 API | 지도 표시와 실제 경로 조회 | Java–JS 브리지 · 이동수단별 요청 |
| JUnit 5 · H2 · Python/Node 검사 | 조건·저장·자료·사이트 회귀 확인 | 모의 입력·검사 DB, 실제 운영 확인과 구분 |
| Quartz · Worker · Durable Object | 문서 생성·팀원 권한·공유 상태 | 팀 문서 · 보드, 앱 전체 DB 프록시는 아님 |
