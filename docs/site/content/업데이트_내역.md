- 앱의 저장 버튼은 UI-01, 목록·상세 조회는 DB-03에서 연결해요. 현재 편집 완료만으로 DB가 저장되지는 않아요.

## 2026-11-13 · 브랜치 대조와 선행 작업 묶기

- 같은 진행 상태·같은 분야의 작업만 하위 목록으로 묶어요. 다른 상태나 분야의 선행 조건이 하나라도 있으면 독립 카드로 표시하고, 선행 연결은 유지해요.
- 하위 목록을 접어도 바로 다음 하위 작업의 제목은 남아요. 펼치면 설명과 상태 변경 메뉴를 볼 수 있어요.

- `feature/map-integration`의 `d32bc76`과 작업 보드 53개 카드를 대조했어요. DB 저장은 원격 코드에 없어 `DB-02`를 할 일로 정리했어요.
- 초기 문서 작성 완료와 최신 코드 설명 보완을 구분했어요. 주요 문서 4개와 테스트 문서 8개의 보완 범위를 카드에 적었어요.
- 이미 구현된 기능의 확인 카드에는 자동 테스트 범위와 실제 지도·DB·다른 PC에서 확인할 내용을 나눠 적었어요.
- 먼저 끝내야 하는 카드 아래에 다음 작업을 접고 펼치는 하위 목록으로 묶었어요. 작업마다 상태·분야·중요도는 따로 유지돼요.
- 선행 조건이 여러 개면 한 곳에서 표시하고, 설명 창에서 다른 조건도 함께 볼 수 있어요. 검색할 때는 상위 경로도 펼쳐져요.
- 코스 저장 검사를 기다릴 필요가 없는 가격·관리자 권한 작업의 선행 연결을 정리했어요.
