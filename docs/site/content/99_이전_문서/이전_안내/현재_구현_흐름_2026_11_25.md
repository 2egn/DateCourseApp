## 최신 기능 브랜치 · 2026-11-25

만들기·편집·저장 페이지 정리와 명시적 DB 준비, 지도 호버·선택·렌더링 여유, 작은 창 배치와 입력 오류 수정을 반영했어요. 저장 이미지의 지도 불러오기 여부는 로그인 세션 안에서만 기억하며 추가 DB 테이블은 없어요. JDK 21은 설치 검색 후 없으면 개인 Gradle 캐시에 자동 다운로드해요.

## 사용 순서

1. 로그인 후 출발지·인원·전체 반경을 정해요.
2. 편집 화면에서 이동수단과 활동·가격·반경·세부 필터를 정해요.
3. 후보 5·10·20·30곳 중 표시 개수를 선택하고, 장소 상세에서 하나씩 추가해요.
4. 내 코스·다음 장소 조건·추천 후보 중 하나를 열어 순서와 구간 반경을 수정해요.
5. 편집 중 선택한 이동수단의 구간별·누적 이동시간을 갱신해요. 도보·자동차·대중교통과 도보를 지원해요.
6. 편집 완료는 메인 화면 반영이고, 코스 저장은 별도의 DB 저장이에요.
7. 저장 목록은 저장 PNG를 우선 보여줘요. 이미지가 없으면 지도·직선 연결, 지도 실패 시 로컬 연결도를 사용해요. 실제 경로는 조회 버튼을 눌렀을 때만 요청해요.

## 지도 조작

- 장소 핀 클릭: 해당 장소 상세 카드. 빈 지도 클릭: 열린 카드·경로 안내 닫기.
- 경로선·번호 호버: 해당 구간 요약. 클릭: 스크롤 가능한 상세 이동 안내.
- 원 테두리 호버: 전체 허용 범위 또는 다음 장소·편집 구간 검색 범위와 반경. 상시 범례는 없어요.
- 장소 추가: 이전 장소와 새 구간을 중심으로 맞춤. 반경 조절: 현재 원을 중심으로 맞춤.
