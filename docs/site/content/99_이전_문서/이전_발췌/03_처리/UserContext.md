## 지도 준비 세션 · 2026-11-24

`isMapPrepared/markMapPrepared`는 현재 회원이 지도를 불러온 코스 ID만 메모리에 기억해요. `invalidateCourses/close`에서 비우고 새 로그인으로 넘기지 않아요. 추가 DB 구조·해시 비교는 사용하지 않아요. [[08_지도_보충/지도_선택과_저장_지도_준비_2026_11_24|저장 화면 흐름]]을 확인하세요.

## 현재 구현 · 2026-11-23

사용자 프로필·저장 목록과 이미지 조회 캐시를 세션별로 관리해요. 화면 공통 부모에 DB를 상속시키지 않아요.

| 주요 함수·구성 | 역할 |
|---|---|
| `preview()` | 코스·이미지 지문별 PNG 읽기를 캐시해요. 최대 12개를 유지해요. |
| `invalidateCourses()` | 코스 변경 후 저장 목록 캐시를 무효화해요. |
| `close()` | 로그아웃한 세션과 캐시를 닫아요. |

## 하는 일

한 번의 로그인에서 프로필과 저장한 코스 목록을 공유해요. 공통 부모 클래스에 DB 객체를 상속시키기보다 계정별 객체를 화면에 전달해요.

## 주요 함수

| 함수 | 하는 일 |
|---|---|
| `profile() / courses()` | 진행 중이거나 성공한 조회를 재사용하고 실패한 조회는 다시 시도할 수 있어요. |
| `invalidateCourses()` | 코스 저장·수정·삭제 후 다음 조회가 최신 목록을 가져오도록 해요. |
| `preload()` | 로그인 후 프로필과 목록을 미리 읽어요. |
| `close()` | 로그아웃한 객체로 새 조회를 시작하지 못하게 하고 캐시를 비워요. |

## 함께 확인할 점

계정 객체는 DB 연결 풀을 소유하지 않아요. 늦게 도착한 응답을 표시할지는 각 화면에서 현재 계정·요청 버전을 비교해요.
