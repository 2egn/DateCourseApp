이번 검토는 기존 정보로 새 점수·연결성 지표를 만드는 작업과 구분해요. 원본·DB·현재 API 응답 정의에는 있지만 앱 모델·파서·화면에서 사용하지 않는 정보를 확인했어요. 코드·카테고리·DB는 변경하지 않았고 운영 카탈로그 5,628곳과 전체 파일 쌍의 일치를 읽기 전용으로 확인했어요.

현재 소분류명은 상세 필터에 쓰지만 원본 중분류와 업종 코드는 앱에 전달하지 않아요. 횟집은 원본 한식, 파스타/스테이크는 서양식, 베트남식은 동남아시아로 명시돼 있는데 현재 문자열 규칙에서는 기타 식사로 가요. 원본 코드·계층을 보존해 상위 묶음을 정리하는 것이 우선이에요.

카페 2,260곳의 원본 소분류는 전부 카페예요. 빵/도넛 130·떡/한과 68·아이스크림/빙수 39곳은 식사에 있어 카페·디저트 이용 목적에 포함할지 검토할 수 있어요. 빵집에 좌석·커피가 있다고 추정하지 않고, 원본 업종과 사용자 이용 목적을 구분해야 해요. 문화는 원본 공원 종류·시설 구분으로 더 나눌 수 있어요. 추가 여가 원본은 업종 선별이 먼저예요.

| 위치 | 현재 빠진 정보 | 활용 방향 |
|---|---|---|
| DB 장소 정보 | 문화 161곳의 홈페이지 값 | 공식 안내·관람·예약 페이지 링크 |
| 박물관·관광지 원문 | 시설 소개·운영시간·휴관일·교통 안내 | 출처와 기준일을 붙인 상세 안내 |
| 공원 원문 | 공원 종류·면적·시설 원문 | 종류 필터·편의시설 안내 |
| 공공 메뉴 자료 | 현재 선택 장소와 연결되는 메뉴 기록 410행의 원문 목록 | 메뉴명·공시 금액·분량 기준 안내. 가격 산출에는 일부 이미 사용해요. |
| 카카오 장소 검색 | 상세 카테고리·전화 | 확인된 조회 결과의 추가 정보. 상세 URL은 이미 사용해요. |
| 카카오 자동차 경로 | 통행료·택시 추정액·도로별 교통 상태 | 조회한 경로의 참고 요금·교통 정보 |
| TMAP 보행 경로 | 시설·회전 유형·도로명·구간별 정보 | 구조화한 보행 안내. 설명문에 일부 의미가 이미 있을 수 있어요. |

API 항목은 현재 파서와 공식 응답 정의를 대조한 결과예요. 새 실제 경로·장소 조회를 하지는 않았고, 모든 응답에 값이 채워져 온다는 뜻은 아니에요. 대중교통 요금·환승 수, 저장된 전화번호 457곳은 이미 표시하므로 미사용 정보로 세지 않았어요. Google 상세 항목은 파일럿 연동과 main 앱 연동을 구분하고 추가 요청·과금 대상은 현재 보유 값에서 제외해요.

먼저 원본 업종 분류 정리와 기존 홈페이지 표시, 다음으로 소개·운영·휴관·시설·메뉴 원문의 연결을 검토하는 순서가 적합해요. 상세 코드 경로·원본 필드·공식 API 링크·수량 근거는 저장소 `docs/research/place-classification-unused-fields-2026-11-25.md`와 같은 이름의 JSON에 기록했어요. [[보유_자원의_경로_추천_활용_탐색_2026_11_25|이전 연결성 탐색]]은 다른 범위의 당시 기록으로 유지해요.
