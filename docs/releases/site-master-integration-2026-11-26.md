## 문서 구성

이동표 138개에 대해 이전 주소용 aliases와 새 경로를 확인했다. 원래 코드 발췌·source_commit·source_sha256을 보존했고 현재 안내·목차·검토·라이브러리 설명을 갱신했다. 빌드가 외부 노트의 이전 사본을 다시 루트에 게시하지 않도록 처리했다.

## 검증

- 사이트 Node 61개 통과. 새 회귀 검사는 경로 이탈·중복 대상·원본 재등장·코드 블록 보존·문서 변경 차수 승계를 확인한다.
