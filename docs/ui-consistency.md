# UI 공통 기준

새 프레임워크 대신 기존 style.css, UiTheme, 기본 JavaFX 컨트롤을 사용한다.

- 주요 동작(primary): 코랄 배경과 진한 글자. 저장·코스 불러오기·제보 승인 등.
- 일반 동작(secondary/default): 중립 회색. 새로고침·페이지 이동·설정 등.
- 삭제/반려(danger): 연한 붉은 배경과 붉은 글자.
- 링크: 작은 글자와 절제된 색. 보조 기능을 큰 버튼으로 강조하지 않는다.
- 일반 JavaFX 버튼 높이는 36px, 한 줄 입력/선택은 40px로 맞춘다.
  화살표·알림 닫기처럼 작은 컨트롤은 목적에 맞는 기존 크기를 유지한다.
- 로그인/회원가입의 Swing 입력은 기존 54px를 유지하되 같은 색상과 버튼 역할을 사용한다.
- 페이지 제목/본문/보조 안내를 구분한다. 제목 스타일은 Label에만 적용해
  TitledPane 내부의 title 영역이 의도치 않게 커지지 않도록 한다.
- 확인·이름 입력·정정 제보·도보 설정 대화상자도 DialogTheme.apply로 기존 스타일을 사용한다.
- 창이 좁을 때 내 페이지의 작업 버튼은 FlowPane으로 줄바꿈한다.

검증은 주요 FXML 화면과 네이티브 대화상자의 버튼 크기·입력 정렬·역할 색상·제목 크기,
기본 창의 지도/장소 목록 배치 및 긴 텍스트 시안을 포함한다.
