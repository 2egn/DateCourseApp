# 시연 장소 가격 근거 점검

확인일: 2026-11-13. 대상은 앱의 `DCA-DEMO-001`~`009` 9곳이다. 공개 웹 페이지와 보유 공공자료를 대조했다. 유료 API 호출·실제 DB 변경은 하지 않았다.

## 결과

## 확인 자료

### 식당 두 곳: 메뉴 가격은 있으나 적용 기준을 확인해야 함

- [부산시 대모골 안내](https://www.busan.go.kr/depart/goodshops/view?bsshNo=5430&curPage=25): 앱 주소와 일치. 정식 두 종류 각 8,000원. 페이지 하단에 `최근 업데이트 2022-08-08`이 있으나 **메뉴 가격 자체의 조사일인지는 명시되지 않았다.**
- [부산시 부잣집밀면 안내](https://www.busan.go.kr/depart/goodshops/view?bsshNo=4790): 앱 주소와 일치. 물밀면 5,500원·비빔밀면 6,000원. 같은 하단 날짜가 있으며 메뉴 조사일로 단정하지 않는다.
- 보유 `data/places/public/busan/busan_good_price_shops.csv`와 `busan_menu_prices.csv`: [전국 착한가격업소 자료](https://www.data.go.kr/data/3045247/fileData.do), 기록된 자료 기준일 2026-09-30. **자료 기준일은 모든 메뉴를 그날 현장 조사했다는 보장이 아니다.** 메뉴 단위는 `as_listed_portion_unknown`이다.

대모골은 동일 공개 장소 ID에 연결된 착한가격업소 행이 두 개지만, 이를 독립적인 두 곳의 검증으로 세지 않는다. 가격 범위를 만들 때도 중복 메뉴를 제거해야 한다.

### 카페: 한 잔의 기준 메뉴를 정해야 함

- [파노라믹커피부산 소개](https://cafeinbusan.co.kr/?p=35350): 주소·대표 메뉴·운영자 SNS 연결 확인. 해당 소개는 가격표가 아니다.
- [연결된 매장 인스타그램](https://www.instagram.com/panoramic_coffee_busan/): 이번 도구에서는 조회 실패. 가격이 공개되어 있지 않다고 단정할 수 없다.
- [SSG 아메리카노 Tall 교환권](https://www.ssg.com/item/itemView.ssg?itemId=1000555801030): 판매 표시 4,700원. 판매 상품의 가격 근거이며 특정 지점의 현장 가격표 검증을 대신하지 않는다.

향후 카페 예상 비용은 **1인당 기준 음료 한 잔, 디저트·추가 옵션 제외**처럼 계산 범위를 명시한다. 가장 싼 음료와 가장 비싼 세트의 차이를 일반적인 음료 비용으로 표시하지 않는다.

### 도서관: 무료의 대상부터 구분

- [연지동작은도서관 공식 안내](https://www.mcst.go.kr/slibrary/library/detail/1047549)
- [범천작은도서관 공식 안내](https://www.mcst.go.kr/slibrary/library/detail/1047532)

두 안내에서 공립 시설·이용 시간은 확인했지만 이용료는 명시적으로 확인하지 못했다. 무료로 확정할 때는 `일반 열람 무료, 별도 프로그램 제외`와 같은 범위를 근거와 함께 남긴다.

## 과제에서 다음으로 할 일

먼저 **대모골·부잣집밀면·카페 한 곳**만 기준 메뉴를 정해 수동 검증한다. 많은 장소를 자동 수집하기보다 실제 추천 → 선택 → 예상 총비용 계산을 보여줄 작은 표본부터 완성한다.

1. 운영자가 제공한 메뉴판이나 매장 확인으로 메뉴명·분량·최소 주문 조건을 확인한다.
2. 식당은 한 사람의 한 끼, 카페는 한 잔으로 계산할 수 있는 메뉴를 고른다. 공유 요리는 후순위로 둔다.
3. `금액 / 단위 / 포함 메뉴 / 제외 항목 / 출처 / 자료 기준일 / 확인일`을 함께 기록한다.
4. 정확한 현재 가격 확인이 어려우면 **시연용 가정 가격**을 별도 목록에 만들 수 있다. 실제 장소에서 확인한 가격과 표시·출처를 구분해야 한다.

현재 앱은 `PriceEstimate` → `NextPlaceService` → `CostEstimate` 순서로 이미 가격 범위를 처리한다. 위 확인이 끝나면 별도 시연 JSON에 근거 있는 값부터 넣고 추천 상한·인원별 합계를 검증한다. 이번 점검에서는 원본 CSV와 앱 가격 숫자를 변경하지 않았다.
