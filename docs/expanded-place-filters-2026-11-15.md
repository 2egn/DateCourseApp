# 세부 조건 필터 확장

## 화면

- 종류: 기존 한식·중식·일식 등의 큰 분류를 유지한다.
- 세부 업종: 등록된 세부 분류를 그대로 선택한다. 식사 공공자료에는 백반/한정식, 국/탕/찌개류, 냉면/밀면, 국수/칼국수, 돼지고기 구이/찜, 일식 회/초밥, 일식 카레/돈가스/덮밥 등 15가지가 있다. 가게 이름으로 메뉴를 추측하지 않는다.
- 가격 정보 기준: 제한 없음 / 참고 가격만 / 추정 가격만 / 무료만. 참고 가격은 현재 메뉴 검증을 뜻하지 않는다. 무료만은 미확인과 추정 0원을 제외한다. 가격 상한은 계속 적용한다.
- 원하는 특징: 가격·혜택, 교통·접근성, 이용 편의로 묶은 다중 체크박스다. 선택한 특징을 모두 충족해야 한다.
- 세부 조건이 적용된 개수 표시, 활동별 선택 복원, 세부 조건만 초기화를 제공한다.

원본 세부 분류가 없는 장소는 기존 큰 분류를 사용한다. 문화 공공자료의 데이터셋명은 도시공원, 박물관·미술관으로 표시한다. 종류를 바꾸면 해당 종류와 맞지 않는 세부 업종 선택은 해제한다.

## 근거와 표시 범위

현재 공공자료 127곳의 확인된 특징은 역 근접 118곳, 정류장 근접 126곳, 착한가격 20곳, 모범음식점 2곳, 무료입장 1곳이다. 화면 건수는 선택한 활동의 목록 기준이며 현재 반경·가격 조건의 결과 건수와 다르다고 설명한다.

주차, 예약, 단체, 포장, 채식, 야외 좌석, 반려견, 어린이, 휠체어 출입도 기존 모델에 맞춰 지원하지만 확인된 자료가 있는 활동에서만 선택지로 제공한다. 미확인이나 명시적으로 불가인 속성을 긍정 조건으로 노출하지 않는다. 이미 선택된 속성이 데이터 갱신 후 미확인이 되어도 조건을 자동으로 넓히지 않고 선택을 유지한다.

9곳 시연 목록과 127곳 공공 목록, 운영 목록의 선택지는 보유 자료에 따라 다르다. 공공자료 목록에서 더 많은 세부 업종과 공공 특징을 확인할 수 있다.

## 구조와 검증

`NextPlaceCondition`에 세부 업종과 가격 기준을 추가하고 기존 생성자는 기본값으로 호환한다. `NextPlaceService`는 표시 개수를 제한하기 전에 모든 조건을 적용한다. `PlaceFeatureSelector`는 확인된 태그 수와 다중 선택을 담당한다. 검색 0건 회복도 새 조건을 유지하며 사용자가 세부 조건 해제를 선택할 때만 함께 초기화한다. 추가 API 호출이나 DB 변경은 없다.

회귀 검사 282개, 실제 지도/도보 경로 검사 3개 통과. 업종 구분, 특징 동시 충족, 미확인/추정 0원의 무료 제외, 데이터 갱신, 활동별 복원, 기본 조건을 유지하는 초기화를 확인했다. JavaFX로 생성한 필터 화면도 확인했다.
