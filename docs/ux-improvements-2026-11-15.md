# UX 평가 후 개선

## 적용

- 공통 조건과 코스 편집 모두 지도는 왼쪽, 조건/검토는 오른쪽에 배치했다. 기존 화면 전체의 좌우 이동 대신 짧은 페이드로 전환한다.
- 편집 완료 후에는 코스 순서, 가격 요약, 누적 도보 시간과 저장 버튼을 먼저 표시한다. 공통 조건은 접어 두되 다시 열 수 있다. 인원 변경은 예상 총비용에 즉시 반영하며 확정 데이터는 저장/편집 완료 전까지 변경하지 않는다.
- 출발지 선택 여부와 코스 유무에 맞춰 안내를 바꾼다. 경로 설명은 호버 안내와 연결하고 예전의 수동 경로 조회 문구를 제거했다.
- 지도 위 상세 카드 본문은 불투명한 흰 배경과 읽기 쉬운 본문으로 조정했다. 정보 정정 제보는 보조 링크로 유지한다.
- 후보 목록의 가격 미확인 중복을 없애고, 확보된 특징 또는 장소 종류를 한 줄로 표시한다. 목록 선택 동작도 짧게 안내한다.
- 가격 입력 아래에 원 환산 금액을 실시간으로 표시한다. 기존 만원 입력 및 천 원 단위 조절과 저장 형식은 유지한다.
- 정상 상태의 지도 복구 버튼 노출을 줄였다. 공통 화면에서는 지도 오류 때 노출하고, 편집에서는 더보기에서 접근할 수 있다.

## 검색 0건 회복

`CandidateRecoveryService`는 기존 `NextPlaceService`를 재사용해 가격 미확인 포함, 세부 조건 해제, 허용 반경 확대, 가격 상한 변경이 각각 실제 결과를 만드는지 확인한다. 선택 가능한 대안만 건수와 함께 표시한다. 필터는 자동으로 변경하지 않는다. 가격 변경은 입력 필드로 이동하며 사용자가 금액을 정한다.

조건 둘 이상을 바꿔야 하는 경우에는 단일 변경을 해결책처럼 제시하지 않는다. 해당 활동의 남은 장소가 전체 범위에 없을 때도 별도로 안내한다. 데이터 재조회나 추가 API 호출 없이 현재 검색에 사용한 목록에서 계산한다.

## 검증

- 전체 회귀 검사 276개 통과.
- 실제 Kakao/TMAP 검사 3개 통과 및 jar 생성 성공.
- 1100×760 완료 화면에서 오른쪽 패널 및 저장 버튼 경계 검증.
- 실제 1440 화면에서 0건 → 가격 미확인 포함 선택 → 후보 4곳 → 상세 카드 → 장소 추가 → 편집 완료를 직접 확인.
- 1200×850 실제 지도 완료 화면과 도보 경로를 이미지로 확인.
- 로그인이나 실제 사용자 코스 저장 없이 시연 초안으로 검증했다.

실행 중인 앱은 새 지도 리소스와 화면 구조를 사용하도록 재시작해야 한다.
