# 저장 코스 미리보기

플래너의 코스 저장/수정 시 현재 SDK 지도를 저장용으로 정돈해 PNG를 생성하고,
`SavedCourseRepository.saveWithPreview`가 `saved_course_previews.image_png`에 보관한다.
코스/장소 스냅샷이 원본이며 이미지는 보조 자료다. 기존 코스는 다시 저장하면 갱신된다.

## 이미지 구성

1000×650 PNG 상단에 장소 수·인원·예상 비용을 표시한다. 가운데는 1000×520 SDK 지도,
하단은 지도 출처와 직선 경로 안내다. 출발지와 장소를 방문 순서대로 직선 연결하며,
지도 위에 번호와 이름을 표시한다. SDK 지도 전체를 합성해 로고/저작권 영역을 자르지 않는다.
후보 핀·범위 원·검색 UI·상세/경로 팝업은 숨긴다. 기존 장소 목록은 이미지 아래에 유지한다.
저장한 코스 화면에서 이미지를 클릭하거나 Enter를 누르면 확대 창을 연다.

이 과정은 도보 경로 API를 호출하지 않으며 플래너의 기존 도보 기능은 유지한다.
별도 지도나 타일을 수집/병합하지 않고 현재 `PlannerMap`의 SDK 화면 1장을 캡처한다.
JavaFX snapshot과 Java AWT/ImageIO를 사용하므로 추가 라이브러리나 API 키는 필요 없다.

## 캡처와 복구

기존 카메라 이동을 마친 뒤 WebView를 저장용 크기로 조절한다. 브라우저 레이아웃이
반영되면 지도 범위를 맞추고 `tilesloaded` 이벤트 및 타일 이미지 로드를 확인한다.
다음 JavaFX 렌더링 펄스에서 snapshot을 얻은 후 원래 WebView 크기·managed 상태,
지도 중심/배율·원래 오버레이를 복구한다. 대기/캡처가 20초를 넘기거나 실패하면
코스를 저장한다. 같은 요약 내용의 기존 이미지가 있으면 유지하고, 없으면 재시도 안내를 표시한다.

이미지 생성은 DB 트랜잭션 전에 처리한다. PNG 쓰기는 코스 트랜잭션 내부 savepoint로
격리해 이미지 저장 실패가 코스 원본 저장을 막지 않도록 한다. 코스 삭제 시 FK CASCADE로
이미지도 삭제한다. 요약 내용과 렌더러 버전의 SHA-256이 일치하는 이미지만 반환한다.
이름은 화면에 별도로 표시하므로 이름 변경만으로 이미지를 다시 생성할 필요가 없다.

목록 쿼리에는 BLOB를 포함하지 않는다. 선택한 코스 이미지만 회원 소유권과 해시를
확인한 뒤 비동기로 읽는다. 최대 24개를 캐시하며 로그인 전환/로그아웃/목록 무효화 시
갱신한다. 이전 선택이나 이전 목록의 요청 결과는 새 화면을 덮지 못한다.
이미지가 없거나 손상됐을 때도 코스 불러오기를 허용한다.

`CoursePreviewRenderer` 기본 연결도 렌더러는 지도 없는 데모/테스트에서 사용한다.
플래너의 `saveWithPreview`는 캡처 실패 시 연결도를 대신 생성하지 않는다.

## 적용과 검증

`data/sql/11_saved_course_previews.sql`은 테이블만 추가하며 기존 행은 변경하지 않는다.
`./gradlew setupCoursePreviews`로 미리 적용하거나 최초 저장 시 준비한다.
실제 사용자 코스 행을 변경하는 테스트나 기존 코스 일괄 재생성은 수행하지 않는다.

일반 테스트: H2에서 PNG 왕복·소유권·수정·이름 변경·삭제 cascade·렌더러 실패·
PNG DB 쓰기 실패·스키마 없는 이전 설치·캡처 없는 저장을 검증한다.
JavaFX에서 비동기 이미지 표시·재저장 후 캐시 갱신·화면 정리·기본 창 크기 배치를 확인한다.

실제 SDK 검증: `./gradlew coursePreviewLiveTest`.
이미지: `build/ui-preview/saved-course-map-straight-live.png`.
SDK 로딩부터 캡처·출처 영역·번호 라벨·확대 범위·원래 화면 복원까지 확인한다.

## 저장 화면의 정보 배치

지도 영역은 고정 높이 대신 오른쪽 본문에 남는 높이를 사용한다. 하단 방문 장소
목록은 기본 88px(72~104px)의 스크롤 영역으로 제한해 창이 커지면 지도가 커지게 한다.
왼쪽 목록 아래에는 장소 분류별 수, 전체 반경의 의미, 참고/추정/미확인 가격 수,
최근 수정 시각과 저장된 장소 특징을 제공한다. 각 장소 행에는 방문 번호·유형·가격
상태·주요 특징·주소를 표시한다. 모든 정보는 저장된 스냅샷에서 읽는다.
`SavedCoursePresenter`가 표시 값을 구성하며 추가 DB 쿼리나 API 호출은 없다.
920×620 기본 창과 1600×1000 창에서 지도 크기 증가와 장소 목록 높이 제한을 검증한다.

## 첫 저장 준비 시점 보완

지도 로드가 진행 중이면 첫 저장의 캡처 요청을 버리지 않고 SDK/브리지와 표시 크기가
준비될 때까지 유지한다. 준비 후 카메라 이동 종료와 타일 상태를 확인한다.
타일이 캐시되어 새 `tilesloaded` 이벤트가 없는 경우에는 실제 타일 이미지가 모두
로드됐는지와 지도 중심·배율·크기·타일 구성이 400ms 이상 안정적인지를 함께 검사한다.
손상/미완료 타일이 있으면 캡처하지 않는다. 최대 대기 시간은 20초다.

`SaveResult.previewStored`는 이미지 쓰기를 포함한 DB 커밋이 끝난 뒤 반환한다.
화면은 PNG 인코딩 성공 여부가 아닌 이 값으로 미리보기 저장 안내를 결정한다.
재현 테스트: 지연된 SDK 준비 전 첫 요청, 캐시된 타일/이벤트 미발생, 손상 타일,
첫 생성 PNG DB 왕복 및 쓰기 실패, 실제 SDK의 첫 로드 직후/연속 캡처.

## 실패 시 기존 이미지 보존

캡처/렌더링이 실패해 새 PNG가 없더라도 현재 요약 해시와 일치하는 기존 프리뷰는 유지한다.
제목만 변경한 경우도 이미지 내용이 같으므로 재사용한다. 장소/좌표/인원/비용 등이 바뀌어
해시가 다르면 기존 이미지는 무효화한다. 저장 결과는 새로 쓰거나 유효한 기존 이미지를
유지한 경우 모두 `previewStored=true`로 반환한다.

## 사용자 재시도

미리보기가 없을 때 저장한 코스 화면의 ‘미리보기 만들기’ 링크로 이미지만 생성한다.
조회 오류에는 ‘다시 불러오기’를 제공한다. 코스 내용과 최근 수정 시각은 바뀌지 않으며
새 이미지 저장 중에는 다른 창에서 변경된 코스를 덮지 못하도록 현재 해시를 재검증한다.
취소하면 기존 코스를 유지한다. 사용자 안내와 안전한 콘솔 진단 규칙은
[사용자 안내와 진단 정보](user-feedback-and-diagnostics.md)를 참고한다.
