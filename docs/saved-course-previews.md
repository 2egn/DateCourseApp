# 저장 코스 미리보기

코스 저장/수정 시 `CoursePreviewImage`가 PNG(1000×420)를 생성하고,
`SavedCourseRepository`가 `saved_course_previews.image_png`에 저장한다.
Java AWT/ImageIO를 사용하므로 별도 API 키나 브라우저 캡처가 필요 없다.

이미지는 방문 순서, 지리적 위치 연결도, 인원, 비용 요약을 담는다.
직선 연결도이며 실제 도보 경로가 아니다. 제목은 화면에 별도로 표시하므로
이름 변경만으로 이미지를 다시 생성할 필요가 없다. 7곳 이상이면 처음 6곳과
나머지 장소 수를 표시하고, 전체 순서는 기존 장소 목록으로 제공한다.

코스/장소 스냅샷이 원본이다. PNG는 보조 자료로, 렌더링/저장 실패 시에도
코스는 저장한다. PNG 쓰기는 코스 트랜잭션 내부 savepoint로 격리하며,
기존 이미지와 현재 요약 내용의 SHA-256이 다르면 프리뷰를 반환하지 않는다.
코스 삭제 시 FK CASCADE로 이미지도 삭제한다.

저장한 코스 목록 쿼리에는 BLOB를 포함하지 않는다. 선택한 코스의 이미지만
회원 소유권과 내용 해시를 확인한 뒤 비동기로 조회한다. 화면은 최대 24개의
이미지를 캐시하며, 로그인 전환/로그아웃/코스 목록 무효화 시 갱신한다.
빠르게 선택을 전환한 경우 이전 요청이 새 선택의 이미지를 덮지 못한다.
이미지 없음/조회 실패/손상 시 안내를 표시하고 코스 불러오기는 허용한다.

`data/sql/11_saved_course_previews.sql`은 테이블을 추가하며 기존 행은 변경하지 않는다.
`./gradlew setupCoursePreviews`로 미리 적용하거나 최초 코스 저장 시 준비한다.
이전 코스는 다음 저장 때 이미지가 생성된다. 기존 코스 일괄 재생성은 수행하지 않는다.

검증: H2 MySQL 모드에서 PNG 왕복, 소유권, 갱신, 이름 변경, 삭제 cascade,
렌더러 실패, PNG DB 쓰기 실패, 스키마 없는 이전 설치를 검증한다.
JavaFX 테스트에서 DB 이미지 비동기 로드, 재저장 후 캐시 갱신, 화면 정리를
확인하고 1000×680/920×620 배치를 검사한다.
시안: `build/ui-preview/saved-course-preview.png`.
