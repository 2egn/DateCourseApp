## 기능과 파일의 관계

한 기능이 화면·모델·서비스·DB에 걸쳐 동작하므로 같은 클래스가 여러 문서에 등장할 수 있다. 이 목차는 기능을 기준으로, 기존 [Java 색인](../08-class-index.md)은 파일을 기준으로 찾는 자료다.

일반 앱 기능·관리자 작업·자료 준비·팀 사이트를 구분한다. 파일럿·후속 후보 탐색 실험·보관 예제는 운영 기능으로 세지 않고 [자료·운영 설명](../06-data-and-operations.md)과 [전체 파일 색인](../09-project-index.md)에서 확인한다.
