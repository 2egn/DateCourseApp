## 코드 주석

현재 Java 코드의 역할·처리 흐름·사용 목적은 짧은 한국어 주석으로 보완했다. 기존 사용자 주석과 실행문은 유지했다. 기능 설명은 변경하지 않았으며 클래스 색인의 선언 위치·소스 지문은 주석 보완 커밋에 맞춰 갱신한다.

## 색인 재생성

프로젝트 루트에서 `python docs/implementation-reference/build-index.py`를 실행한다. 역할·대표 선언·파일 목록·coverage.json만 갱신하며 앞의 기능 설명을 자동으로 다시 쓰지 않는다. 구현이나 현재 자료가 소스 기준과 다르면 중단한다. 먼저 핵심 문서를 대조·수정하고 이 문서의 소스 기준 커밋을 갱신해야 한다. 현재 범위는 활성 Java 99개·공유 추적 파일 784개다.

[재생성 도구](build-index.py) · [범위·지문 목록](coverage.json). 핵심 문서의 설명과 색인·해시의 일치는 별개로 검토한다.
